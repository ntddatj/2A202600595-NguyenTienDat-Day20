# Webviz Teaching GUI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a no-build-step web GUI (`webviz/`) that runs the real `src/multi_agent_research_lab` LangGraph workflow in mock mode and visualizes shared state, graph routing, metrics, and per-feature teaching lessons live as the workflow streams.

**Architecture:** A FastAPI backend monkeypatches the real `LLMClient`/`SearchClient` with deterministic fakes (mock mode default), builds the real `MultiAgentWorkflow`, and runs `compiled.stream()`, mapping each LangGraph node emission into a typed SSE event. A vanilla HTML/CSS/JS frontend consumes the SSE stream to light up nodes, fill the state "clipboard", update metrics, and auto-open lesson narration the instant a toggle is flipped. The real `render_markdown_report` produces the exportable benchmark report.

**Tech Stack:** FastAPI, sse-starlette (or StreamingResponse), uvicorn, vanilla HTML/CSS/JS (no build step), pytest. Runs the real src/ workflow via LangGraph `.stream()`; Mock mode default via monkeypatched fakes.

## Global Constraints

- Do NOT modify anything under `src/` (the graded submission) or `rebuild-practice/`; the plan only reads/excerpts from them.
- Python `>=3.11` (matches `pyproject.toml requires-python`).
- Mock mode is the default: deterministic, fully offline, no API key required.
- Live mode (OpenAI/Tavily) is opt-in; missing API key produces a friendly `error` event suggesting to disable Live — never a 500.
- The loop demo has a hard cap of 20 iterations even when the `max_iterations` guardrail is toggled off; the backend emits a warning when the cap fires.
- Tracing is best-effort/fail-open: a tracing failure must NOT crash the server; the workflow still completes and the UI shows a fail-open banner.
- Narration is in Vietnamese with English technical terms glossed inline (first occurrence) plus hover glossary chips.
- New code lives ONLY in `webviz/` and `tests/webviz/`. The only permitted edit outside those is adding the `viz` optional-dependency group to `pyproject.toml`.

```python
"""Typed contracts shared by the backend stream, server, lessons, and frontend."""

from __future__ import annotations

from typing import Any, Literal

from pydantic import BaseModel, Field

EventKind = Literal["step", "start", "done", "error", "warning"]


class Lane(BaseModel):
    """Splits state fields into control-plane (drives routing) vs observability."""

    control: dict[str, Any] = Field(default_factory=dict)
    observability: dict[str, Any] = Field(default_factory=dict)


class StreamEvent(BaseModel):
    """One SSE frame describing a single workflow step."""

    step: int
    active_node: str
    edge_taken: str | None
    state_snapshot: dict[str, Any]
    metrics: dict[str, Any]
    lane: Lane
    note: str
    kind: EventKind = "step"


class GlossaryEntry(BaseModel):
    term: str
    vi: str


class LessonOption(BaseModel):
    label: str
    code: str
    narration: str
    source_ref: str | None = None


class Lesson(BaseModel):
    id: str
    title: str
    option_a: LessonOption
    option_b: LessonOption
    glossary: list[GlossaryEntry] = Field(default_factory=list)
```

```python
"""Deterministic, offline drop-in replacements for the real service clients.

Signatures mirror src/multi_agent_research_lab/services exactly so they can be
monkeypatched in without touching src/.
"""

from __future__ import annotations

from dataclasses import dataclass

from multi_agent_research_lab.core.schemas import SourceDocument

_COST_PER_1M_INPUT = 0.15  # mirrors llm_client.py:16
_COST_PER_1M_OUTPUT = 0.60  # mirrors llm_client.py:17


class FakeLLMError(Exception):
    """Raised by FakeLLMClient when fault injection is active."""


class FakeSearchError(Exception):
    """Raised by FakeSearchClient when fault injection is active."""


@dataclass(frozen=True)
class FakeLLMResponse:
    content: str
    input_tokens: int | None = None
    output_tokens: int | None = None
    cost_usd: float | None = None


def _cost(input_tokens: int, output_tokens: int) -> float:
    return (input_tokens * _COST_PER_1M_INPUT + output_tokens * _COST_PER_1M_OUTPUT) / 1_000_000


def make_default_sources() -> list[SourceDocument]:
    return [
        SourceDocument(
            title="Multi-agent systems overview",
            url="https://example.test/overview",
            snippet="Multiple specialised agents coordinate via shared state.",
            metadata={"score": 0.91},
        ),
        SourceDocument(
            title="Why supervisors route by state",
            url="https://example.test/supervisor",
            snippet="A router reads what is missing and picks the next worker.",
            metadata={"score": 0.84},
        ),
        SourceDocument(
            title="Benchmarking agent pipelines",
            url="https://example.test/benchmark",
            snippet="Compare latency, cost, and citation coverage objectively.",
            metadata={"score": 0.77},
        ),
    ]


def _role_answer(system_prompt: str) -> tuple[str, int, int]:
    """Return (content, input_tokens, output_tokens) keyed off the system prompt."""
    sp = system_prompt.lower()
    if "research specialist" in sp:
        return ("Research notes:\n1. Key fact [1]\n2. Supporting figure [2]", 120, 60)
    if "critical analyst" in sp:
        return ("## Analysis\nClaims are well supported; evidence is moderate.", 140, 70)
    if "technical writer" in sp:
        return (
            "## Answer\nA clear, structured response citing sources [1][2][3].",
            180,
            150,
        )
    # baseline single-call assistant (cli.py _BASELINE_SYSTEM)
    return ("A concise single-pass answer to the query.", 90, 110)


class FakeLLMClient:
    """Drop-in for src ...services.llm_client.LLMClient."""

    def __init__(self, fault: str = "none") -> None:
        self._fault = fault
        self._calls = 0

    def complete(self, system_prompt: str, user_prompt: str) -> FakeLLMResponse:
        self._calls += 1
        if self._fault == "always" or (self._fault == "first" and self._calls == 1):
            raise FakeLLMError("injected transient LLM failure")
        content, in_tok, out_tok = _role_answer(system_prompt)
        return FakeLLMResponse(
            content=content,
            input_tokens=in_tok,
            output_tokens=out_tok,
            cost_usd=_cost(in_tok, out_tok),
        )


class FakeSearchClient:
    """Drop-in for src ...services.search_client.SearchClient."""

    def __init__(
        self, results: list[SourceDocument] | None = None, fault: str = "none"
    ) -> None:
        self._results = make_default_sources() if results is None else results
        self._fault = fault
        self._calls = 0

    def search(self, query: str, max_results: int = 5) -> list[SourceDocument]:
        self._calls += 1
        if self._fault == "always" or (self._fault == "first" and self._calls == 1):
            raise FakeSearchError("injected search failure")
        return list(self._results[:max_results])
```

## Task 4: scenarios.py — toggles → RunConfig

The real defaults this must respect: `Settings.max_iterations` default 6, validated `le=20` (`src/multi_agent_research_lab/core/config.py:28`). The supervisor forces `done` when `iteration >= max_iterations` (`src/multi_agent_research_lab/agents/supervisor.py:25-27`). The retry decorator lives on `LLMClient.complete` (`src/multi_agent_research_lab/services/llm_client.py:38`). Note: the real `SearchClient` has NO retry wrapper, so with a fault flag set, search dies regardless of the `retry` toggle.

**Files:**
- Create: `webviz/scenarios.py`
- Test: `tests/webviz/test_scenarios.py`

**Interfaces:**
- Consumes: nothing from earlier tasks.
- Produces:
  - `Toggles(multi: bool = True, retry: bool = True, max_iterations: bool = True, search: bool = True)` (Pydantic model).
  - `RunConfig` (Pydantic model) with fields: `runner: str` (`"multi"` or `"baseline"`), `live: bool`, `query: str`, `llm_fault: str` (`"none"|"first"|"always"`), `search_fault: str`, `search_empty: bool`, `strip_llm_retry: bool`, `iteration_cap: int` (always `<= 20`), `enforce_default_max: bool`, `starve_final_answer: bool`.
  - `HARD_CAP = 20` module constant.
  - `build_run_config(toggles: Toggles, live: bool, query: str) -> RunConfig`.

Toggle semantics encoded:
- `multi=False` → `runner="baseline"`.
- `retry=False` → `strip_llm_retry=True` AND `llm_fault="first"` (LLM would die without retry; with retry it heals). `search_fault` set to `"always"` only when `retry=False` (search has no retry, so it dies) — this directly demonstrates the spec line "Search luôn chết vì không có retry".
- `max_iterations=False` → `enforce_default_max=False`, `iteration_cap=HARD_CAP` (=20) AND `starve_final_answer=True`. Starving `final_answer` is what makes the guardrail demonstrable: without it the happy path fills `final_answer` and the supervisor returns "done" at ~iteration 4, so the hard cap would never fire and the toggle would be a visual no-op. With `starve_final_answer`, the writer node is stubbed to leave `final_answer = None`, so the supervisor keeps routing supervisor→writer→supervisor (each route increments `iteration`) until `iteration >= 20` forces "done" — proving the hard cap. When on: `enforce_default_max=True`, `iteration_cap=6`, `starve_final_answer=False`.
- `search=False` → `search_empty=True` (FakeSearchClient returns `[]` → coverage 0).

```python
"""Pure mapping from UI toggles to a concrete run configuration."""

from __future__ import annotations

from pydantic import BaseModel

HARD_CAP = 20  # backend hard ceiling for the loop demo (spec section 7)
DEFAULT_MAX = 6  # mirrors config.py Settings.max_iterations default


class Toggles(BaseModel):
    multi: bool = True
    retry: bool = True
    max_iterations: bool = True
    search: bool = True


class RunConfig(BaseModel):
    runner: str  # "multi" | "baseline"
    live: bool
    query: str
    llm_fault: str = "none"      # "none" | "first" | "always"
    search_fault: str = "none"
    search_empty: bool = False
    strip_llm_retry: bool = False
    iteration_cap: int = DEFAULT_MAX
    enforce_default_max: bool = True
    starve_final_answer: bool = False


def build_run_config(toggles: Toggles, live: bool, query: str) -> RunConfig:
    cfg = RunConfig(
        runner="multi" if toggles.multi else "baseline",
        live=live,
        query=query,
    )

    if not toggles.retry:
        # Without the @retry layer a transient LLM error is fatal; we inject a
        # first-call fault to show retry healing it when ON. Search has no retry
        # in src/, so an injected fault is always fatal there.
        cfg.strip_llm_retry = True
        cfg.llm_fault = "first"
        cfg.search_fault = "always"

    if not toggles.max_iterations:
        cfg.enforce_default_max = False
        cfg.iteration_cap = HARD_CAP
        # Starve final_answer so the supervisor genuinely loops on the writer
        # until the hard cap forces "done" — otherwise the toggle is a no-op
        # because the happy path returns "done" at ~iteration 4.
        cfg.starve_final_answer = True
    else:
        cfg.enforce_default_max = True
        cfg.iteration_cap = DEFAULT_MAX
        cfg.starve_final_answer = False

    if not toggles.search:
        cfg.search_empty = True

    # Safety: never let the cap exceed the hard ceiling.
    cfg.iteration_cap = min(cfg.iteration_cap, HARD_CAP)
    return cfg
```

```python
from __future__ import annotations

from collections.abc import Iterator
from contextlib import ExitStack, contextmanager, nullcontext
from typing import Any
from unittest.mock import patch

from multi_agent_research_lab.core.schemas import AgentName, AgentResult, ResearchQuery
from multi_agent_research_lab.core.state import ResearchState
from multi_agent_research_lab.graph.workflow import MultiAgentWorkflow

from webviz.contracts import Lane, StreamEvent
from webviz.fakes import FakeLLMClient, FakeSearchClient
from webviz.scenarios import DEFAULT_MAX, HARD_CAP, RunConfig

)

_WORKER_NODES = {"researcher", "analyst", "writer"}


def _settings_stub(max_iterations: int) -> Any:
    class _S:
        pass

    s = _S()
    s.max_iterations = max_iterations
    return s


def _starving_writer_run(self: Any, state: ResearchState) -> ResearchState:
    """Writer stub that records work but NEVER fills final_answer.

    Used only when config.starve_final_answer is True (max_iterations toggle
    off). It keeps the supervisor routing supervisor→writer→supervisor so
    `iteration` climbs until the hard cap forces "done", demonstrating the
    guardrail instead of letting the happy path finish at ~iteration 4.
    """
    state.agent_results.append(
        AgentResult(
            agent=AgentName.WRITER,
            content="(starved: final_answer intentionally left empty)",
            metadata={"output_tokens": 0, "starved": True},
        )
    )
    state.add_trace_event("writer.starved", {"iteration": state.iteration})
    state.final_answer = None
    return state


@contextmanager
def _mock_patches(config: RunConfig) -> Iterator[None]:
    """Monkeypatch service clients + supervisor settings; src/ stays untouched."""
    llm_factory = lambda: FakeLLMClient(fault=config.llm_fault)  # noqa: E731
    if config.search_empty:
        search_factory = lambda: FakeSearchClient(results=[])  # noqa: E731
    else:
        search_factory = lambda: FakeSearchClient(fault=config.search_fault)  # noqa: E731

    with ExitStack() as stack:
        stack.enter_context(
            patch("multi_agent_research_lab.agents.researcher.LLMClient", llm_factory)
        )
        stack.enter_context(
            patch("multi_agent_research_lab.agents.analyst.LLMClient", llm_factory)
        )
        stack.enter_context(
            patch("multi_agent_research_lab.agents.writer.LLMClient", llm_factory)
        )
        stack.enter_context(
            patch("multi_agent_research_lab.agents.researcher.SearchClient", search_factory)
        )
        stack.enter_context(
            patch(
                "multi_agent_research_lab.agents.supervisor.get_settings",
                lambda: _settings_stub(config.iteration_cap),
            )
        )
        if config.starve_final_answer:
            stack.enter_context(
                patch(
                    "multi_agent_research_lab.agents.writer.WriterAgent.run",
                    _starving_writer_run,
                )
            )
        yield


def _coverage(state: ResearchState) -> float:
    import re

    if not state.final_answer or not state.sources:
        return 0.0
    n = len(state.sources)
    cited = sum(1 for i in range(1, n + 1) if re.search(rf"\[{i}\]", state.final_answer))
    return round(cited / n, 2)


def _cost(state: ResearchState) -> float:
    total = 0.0
    for r in state.agent_results:
        out = r.metadata.get("output_tokens") or 0
        inp = r.metadata.get("input_tokens") or 0
        total += (inp * 0.15 + out * 0.60) / 1_000_000
    return round(total, 6)


def _metrics(state: ResearchState) -> dict[str, Any]:
    return {
        "iteration": state.iteration,
        "agents_run": len(state.agent_results),
        "sources": len(state.sources),
        "cost_usd": _cost(state),
        "citation_coverage": _coverage(state),
    }


def _snapshot(state: ResearchState) -> dict[str, Any]:
    return {
        "research_notes": "✔" if state.research_notes else None,
        "analysis_notes": "✔" if state.analysis_notes else None,
        "final_answer": "✔" if state.final_answer else None,
        "sources": len(state.sources),
    }


def _lane(state: ResearchState) -> Lane:
    return Lane(
        control={"iteration": state.iteration, "route_history": list(state.route_history)},
        observability={"trace_len": len(state.trace), "errors": len(state.errors)},
    )


def _note(node: str, state: ResearchState) -> str:
    if node == "supervisor" and state.route_history:
        return f"iter {state.iteration} · supervisor → {state.route_history[-1]}"
    return f"{node} cập nhật state"


def _patch_ctx(config: RunConfig):
    """Apply fakes only in mock mode; live mode uses the REAL clients."""
    return _mock_patches(config) if not config.live else nullcontext()


def final_state(config: RunConfig) -> ResearchState:
    state = ResearchState(request=ResearchQuery(query=config.query))
    with _patch_ctx(config):
        compiled = MultiAgentWorkflow().build()
        result = compiled.invoke({"research_state": state})
    return result["research_state"]


def run_stream(config: RunConfig) -> Iterator[StreamEvent]:
    yield StreamEvent(
        step=0,
        active_node="entry",
        edge_taken=None,
        state_snapshot={},
        metrics={},
        lane=Lane(),
        note=f"Bắt đầu (mock={not config.live}) cap={config.iteration_cap}",
        kind="start",
    )
    step = 0
    last_state: ResearchState | None = None
    try:
        state = ResearchState(request=ResearchQuery(query=config.query))
        with _patch_ctx(config):
            compiled = MultiAgentWorkflow().build()
            # 4 * HARD_CAP + 5 fits ~20 supervisor + ~20 writer steps when
            # starving final_answer (supervisor→writer→supervisor each loop).
            for update in compiled.stream(
                {"research_state": state}, {"recursion_limit": 4 * HARD_CAP + 5}
            ):
                for node_name, node_out in update.items():
                    rs = node_out["research_state"]
                    last_state = rs
                    step += 1
                    edge = rs.route_history[-1] if node_name == "supervisor" and rs.route_history else None
                    yield StreamEvent(
                        step=step,
                        active_node=node_name,
                        edge_taken=edge,
                        state_snapshot=_snapshot(rs),
                        metrics=_metrics(rs),
                        lane=_lane(rs),
                        note=_note(node_name, rs),
                    )
                    if rs.iteration >= HARD_CAP and rs.final_answer is None:
                        yield StreamEvent(
                            step=step,
                            active_node=node_name,
                            edge_taken=None,
                            state_snapshot=_snapshot(rs),
                            metrics=_metrics(rs),
                            lane=_lane(rs),
                            note=f"Chạm trần cứng {HARD_CAP} vòng — dừng (guardrail).",
                            kind="warning",
                        )
    except Exception as exc:  # fail-soft: surface as an event, never 500
        yield StreamEvent(
            step=step + 1,
            active_node="error",
            edge_taken=None,
            state_snapshot=_snapshot(last_state) if last_state else {},
            metrics=_metrics(last_state) if last_state else {},
            lane=_lane(last_state) if last_state else Lane(),
            note=f"Lỗi runtime: {type(exc).__name__}: {exc}",
            kind="error",
        )
        return

    final = last_state if last_state else ResearchState(request=ResearchQuery(query=config.query))
    yield StreamEvent(
        step=step + 1,
        active_node="done",
        edge_taken=None,
        state_snapshot=_snapshot(final),
        metrics=_metrics(final),
        lane=_lane(final),
        note="Hoàn tất workflow.",
        kind="done",
    )


def run_baseline_stream(config: RunConfig) -> Iterator[StreamEvent]:
    yield StreamEvent(
        step=0,
        active_node="baseline",
        edge_taken=None,
        state_snapshot={"final_answer": None},
        metrics={},
        lane=Lane(),
        note="Baseline 1-call: gọi LLM một lần.",
        kind="start",
    )
    llm = FakeLLMClient(fault=config.llm_fault)
    try:
        resp = llm.complete(_BASELINE_SYSTEM, config.query)
        metrics = {
            "cost_usd": round(((resp.input_tokens or 0) * 0.15 + (resp.output_tokens or 0) * 0.60) / 1_000_000, 6),
            "agents_run": 1,
            "citation_coverage": 0.0,
        }
        yield StreamEvent(
            step=1,
            active_node="baseline",
            edge_taken=None,
            state_snapshot={"final_answer": "✔"},
            metrics=metrics,
            lane=Lane(control={"iteration": 1}, observability={"trace_len": 0}),
            note="Baseline xong (1 agent, không trích nguồn).",
            kind="done",
        )
    except Exception as exc:
        yield StreamEvent(
            step=1,
            active_node="error",
            edge_taken=None,
            state_snapshot={},
            metrics={},
            lane=Lane(),
            note=f"Lỗi baseline: {type(exc).__name__}: {exc}",
            kind="error",
        )


def run_any(config: RunConfig) -> Iterator[StreamEvent]:
    if config.runner == "baseline":
        yield from run_baseline_stream(config)
    else:
        yield from run_stream(config)
```

```python
"""Load and validate teaching lessons from webviz/lessons/*.json."""

from __future__ import annotations

import json
from pathlib import Path

from pydantic import ValidationError

from webviz.contracts import Lesson

LESSONS_DIR = Path(__file__).resolve().parent / "lessons"


def load_lessons() -> dict[str, Lesson]:
    lessons: dict[str, Lesson] = {}
    for path in sorted(LESSONS_DIR.glob("*.json")):
        try:
            data = json.loads(path.read_text(encoding="utf-8"))
            lesson = Lesson.model_validate(data)
        except (json.JSONDecodeError, ValidationError) as exc:
            raise ValueError(f"Invalid lesson file {path.name}: {exc}") from exc
        lessons[lesson.id] = lesson
    return lessons


def lesson_ids() -> list[str]:
    return list(load_lessons().keys())
```

```python
"""FastAPI app serving the teaching GUI, SSE run stream, report, and lessons."""

from __future__ import annotations

from pathlib import Path

from fastapi import FastAPI
from fastapi.responses import FileResponse, StreamingResponse
from fastapi.staticfiles import StaticFiles
from pydantic import BaseModel

from multi_agent_research_lab.core.schemas import BenchmarkMetrics
from multi_agent_research_lab.evaluation.report import render_markdown_report
from webviz.contracts import StreamEvent
from webviz.fakes import FakeLLMClient
from webviz.lessons_loader import load_lessons
from webviz.scenarios import Toggles, build_run_config
from webviz.stream import _BASELINE_SYSTEM, _cost, _coverage, final_state, run_any

STATIC_DIR = Path(__file__).resolve().parent / "static"

app = FastAPI(title="webviz — Multi-Agent Research Lab teaching GUI")
app.mount("/static", StaticFiles(directory=str(STATIC_DIR)), name="static")


class RunRequest(BaseModel):
    query: str = "what is multi agent system design"
    live: bool = False
    toggles: Toggles = Toggles()


class ReportRequest(BaseModel):
    query: str = "what is multi agent system design"
    toggles: Toggles = Toggles()


@app.get("/")
def index() -> FileResponse:
    return FileResponse(str(STATIC_DIR / "index.html"))


@app.get("/lessons")
def lessons() -> dict:
    data = [lesson.model_dump() for lesson in load_lessons().values()]
    return {"lessons": data}


def _sse(event: StreamEvent) -> str:
    return f"data: {event.model_dump_json()}\n\n"


@app.post("/run")
def run(req: RunRequest) -> StreamingResponse:
    config = build_run_config(req.toggles, live=req.live, query=req.query)

    def gen():
        for event in run_any(config):
            yield _sse(event)

    return StreamingResponse(gen(), media_type="text/event-stream")


def _multi_metrics(query: str, toggles: Toggles) -> tuple[BenchmarkMetrics, float]:
    """Return (metrics, real_cost) for the multi-agent run."""
    config = build_run_config(toggles, live=False, query=query)
    state = final_state(config)
    cost = _cost(state)
    coverage = _coverage(state)
    metrics = BenchmarkMetrics(
        run_name="multi-agent",
        latency_seconds=0.0,
        estimated_cost_usd=cost if cost > 0 else None,
        notes=f"citation_coverage={coverage} agents={len(state.agent_results)}",
    )
    return metrics, cost


def _baseline_metrics(query: str) -> tuple[BenchmarkMetrics, float]:
    """Real deterministic baseline: one FakeLLMClient call, no sources."""
    resp = FakeLLMClient().complete(_BASELINE_SYSTEM, query)
    cost = round(
        ((resp.input_tokens or 0) * 0.15 + (resp.output_tokens or 0) * 0.60) / 1_000_000, 6
    )
    metrics = BenchmarkMetrics(
        run_name="single-agent-baseline",
        latency_seconds=0.0,
        estimated_cost_usd=cost if cost > 0 else None,
        notes="citation_coverage=0.0 agents=1",
    )
    return metrics, cost


@app.post("/report")
def report(req: ReportRequest) -> dict:
    multi_toggles = req.toggles.model_copy(update={"multi": True})
    baseline, baseline_cost = _baseline_metrics(req.query)
    multi, multi_cost = _multi_metrics(req.query, multi_toggles)
    markdown = render_markdown_report([baseline, multi], query=req.query)
    return {"markdown": markdown, "costs": {"single": baseline_cost, "multi": multi_cost}}
```

Note: `_cost`, `_coverage`, and `_BASELINE_SYSTEM` are imported from `webviz.stream` (defined in Task 5). The baseline cost is REAL — derived from the same deterministic `FakeLLMClient` the workflow uses — so the single-vs-multi cost gap is genuine, not hardcoded.

```javascript
"use strict";

const $ = (sel) => document.querySelector(sel);
const $$ = (sel) => Array.from(document.querySelectorAll(sel));

let LESSONS = {};
let currentSpeed = () => Number($("#speed").value);

// Map each toggle key to its lesson id (spec section 10).
const TOGGLE_LESSON = {
  multi: "route-by-state",
  retry: "retry-timeout",
  max_iterations: "max-iterations",
  search: "search-grounding",
};

const NODE_HATS = {
  researcher: "You are a research specialist. ... Number each key point.",
  analyst: "You are a critical analyst. ... Structure your response with clear headings.",
  writer: "You are a technical writer targeting {audience}. ... cite sources with [N].",
  supervisor: "(supervisor không gọi LLM — chỉ điều phối theo state)",
};

// ---- glossary inline rendering -------------------------------------------
function renderGloss(text, glossary) {
  let html = escapeHtml(text);
  for (const g of glossary) {
    const re = new RegExp(`\\b(${escapeReg(g.term)})\\b`, "i");
    html = html.replace(
      re,
      `<span class="gloss" title="${escapeHtml(g.vi)}">$1</span>`
    );
  }
  return html;
}
function escapeHtml(s) {
  return s.replace(/[&<>]/g, (c) => ({ "&": "&amp;", "<": "&lt;", ">": "&gt;" }[c]));
}
function escapeReg(s) {
  return s.replace(/[.*+?^${}()|[\]\\]/g, "\\$&");
}

// ---- lesson panel ---------------------------------------------------------
function showLesson(id, option /* "a" | "b" */, deltaText) {
  const lesson = LESSONS[id];
  if (!lesson) return;
  const opt = option === "b" ? lesson.option_b : lesson.option_a;
  const other = option === "b" ? lesson.option_a : lesson.option_b;
  $("#lesson-title").textContent = lesson.title;
  $("#opt-label").textContent = opt.label;
  $("#source-ref").textContent = opt.source_ref ? `nguồn: ${opt.source_ref}` : "(counterfactual)";
  $("#lesson-code").textContent = opt.code;
  $("#compare-other").textContent = `↔ phương án còn lại: ${other.label}`;
  $("#narration").innerHTML = renderGloss(opt.narration, lesson.glossary);
  const gl = $("#glossary-list");
  gl.innerHTML = "";
  for (const g of lesson.glossary) {
    const li = document.createElement("li");
    li.innerHTML = `<b>${escapeHtml(g.term)}</b>: ${escapeHtml(g.vi)}`;
    gl.appendChild(li);
  }
  if (deltaText) {
    $("#delta-line").hidden = false;
    $("#delta-line").textContent = deltaText;
  }
}

function switchTab(name) {
  $$(".tab").forEach((t) => t.classList.toggle("active", t.dataset.tab === name));
  $("#tab-code").hidden = name !== "code";
  $("#tab-narration").hidden = name !== "narration";
}

// Toggle flip => jump to lesson + open Thuyết minh + show trước→sau (spec 5.2).
function onToggle(key, checked) {
  const id = TOGGLE_LESSON[key];
  const before = checked ? "TẮT" : "BẬT";
  const after = checked ? "BẬT" : "TẮT";
  const consequence = {
    multi: checked ? "dùng nhiều agent chuyên biệt" : "chỉ 1 lần gọi LLM, không trích nguồn",
    retry: checked ? "lỗi mạng tạm thời tự hồi phục" : "1 lỗi mạng tạm thời làm chết cả workflow",
    max_iterations: checked ? "có trần vòng lặp an toàn" : "không trần → dựa vào trần cứng 20 ở backend",
    search: checked ? "có nguồn → coverage > 0" : "không nguồn → coverage = 0",
  }[key];
  showLesson(id, checked ? "a" : "b",
    `${key}: ${before} → ${after} · ${consequence}`);
  switchTab("narration");
}

// ---- graph + state rendering ---------------------------------------------
function setActiveNode(node) {
  $$(".node").forEach((n) => n.classList.toggle("active", n.dataset.node === node));
}
function animateEdge(edgeName) {
  $$(".edge").forEach((e) => e.classList.remove("animate"));
  const el = document.querySelector(`.edge[data-edge="${edgeName}"]`);
  if (el) el.classList.add("animate");
}
const FIELD_WRITER = {
  researcher: ["sources", "research_notes"],
  analyst: ["analysis_notes"],
  writer: ["final_answer"],
};
function paintState(snapshot, activeNode) {
  for (const li of $$("#state-fields li")) {
    const field = li.dataset.field;
    const v = snapshot[field];
    const valEl = li.querySelector(".val");
    if (v === "✔" || (field === "sources" && typeof v === "number" && v > 0)) {
      valEl.textContent = field === "sources" ? v : "✔";
      valEl.classList.add("done");
    } else {
      valEl.textContent = v === null || v === undefined ? "None" : v;
    }
    li.classList.remove("read", "write");
    const writes = FIELD_WRITER[activeNode] || [];
    if (writes.includes(field)) li.classList.add("write");
  }
}
function paintLanes(lane) {
  $("#lane-control .lane-body").textContent =
    `iteration=${lane.control.iteration} route=${(lane.control.route_history || []).join("→")}`;
  $("#lane-obs .lane-body").textContent =
    `trace_len=${lane.observability.trace_len} errors=${lane.observability.errors}`;
}

function handleEvent(ev) {
  if (ev.kind === "error") {
    addTrace(`❌ ${ev.note}`);
    setActiveNode("error");
    return;
  }
  if (ev.kind === "warning") { addTrace(`⚠️ ${ev.note}`); return; }
  setActiveNode(ev.active_node);
  if (ev.edge_taken) animateEdge(ev.edge_taken);
  paintState(ev.state_snapshot || {}, ev.active_node);
  if (ev.lane) paintLanes(ev.lane);
  if (NODE_HATS[ev.active_node]) $("#hat").textContent = NODE_HATS[ev.active_node];
  if (ev.active_node === "supervisor" && ev.edge_taken) {
    $("#decision-box").textContent =
      `iter ${ev.lane.control.iteration} → chọn ${ev.edge_taken}`;
  }
  if (ev.metrics) {
    if (ev.metrics.cost_usd !== undefined) $("#m-cost").textContent = `$${ev.metrics.cost_usd}`;
    if (ev.metrics.citation_coverage !== undefined)
      $("#m-coverage").textContent = ev.metrics.citation_coverage;
  }
  addTrace(`#${ev.step} ${ev.active_node}: ${ev.note}`);
}

function addTrace(text) {
  const li = document.createElement("li");
  li.textContent = text;
  $("#trace-log ol").appendChild(li);
}

// ---- run (SSE via fetch streaming) ---------------------------------------
function readToggles() {
  const t = {};
  $$(".toggle").forEach((el) => (t[el.dataset.key] = el.checked));
  return t;
}

async function run() {
  $("#trace-log ol").innerHTML = "";
  $("#fail-open-banner").hidden = true;
  const body = { query: $("#query").value, live: $("#live").checked, toggles: readToggles() };
  const resp = await fetch("/run", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(body),
  });
  const reader = resp.body.getReader();
  const decoder = new TextDecoder();
  let buf = "";
  while (true) {
    const { value, done } = await reader.read();
    if (done) break;
    buf += decoder.decode(value, { stream: true });
    let idx;
    while ((idx = buf.indexOf("\n\n")) >= 0) {
      const chunk = buf.slice(0, idx);
      buf = buf.slice(idx + 2);
      const line = chunk.split("\n").find((l) => l.startsWith("data:"));
      if (!line) continue;
      const ev = JSON.parse(line.slice(5).trim());
      handleEvent(ev);
      if (currentSpeed() > 0) await sleep(currentSpeed());
    }
  }
}
const sleep = (ms) => new Promise((r) => setTimeout(r, ms));

}
```
